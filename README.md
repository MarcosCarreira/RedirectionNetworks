# RedirectionNetworks

Analysis of redirection networks.

- [`CompleteRedirection2022/`](CompleteRedirection2022/README.md): complete redirection, 2022-2023: exact small-N results and closed forms (Mathematica notebook, PDF notes, Python notebooks).
- [`CompleteRedirection2026/`](CompleteRedirection2026/README.md): the growth exponent of complete redirection trees, by an Euler-Lotka equation, a neighbourhood model (within 0.012% of the reference value) and cavity equations on degree paths (within 0.006%), with a paper (`CompleteRedirection2026/paper/`).
